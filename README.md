# Karta ula
Prototyp natywnej aplikacji Android w Kotlinie. Zapis lokalny; bez Bluetooth.
Wymagania: Android SDK 35, JDK 17, Gradle 8.9.
Otwórz ten folder w Android Studio. Projekt nie zawiera jeszcze Gradle Wrapper.
Do budowy przy zainstalowanym Gradle 8.9: gradle assembleDebug.
Brak przeprowadzonej kompilacji i testów na telefonie.
Nie używaj prototypu jako jedynego archiwum danych pasieki.
